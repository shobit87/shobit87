## Hi, I'm Shobhit Kumar

Most recently I was a Senior Data Analyst in Contentsquare's Strategic Services team, where I built AWS data pipelines (Glue, S3, SFTP delivery with SES alerting) and ran digital experience analytics for enterprise clients in financial services and global retail. I like problems where messy business documents or data need to become something a team can trust and act on. My recent focus is agentic workflows: multi agent LangGraph pipelines with critic and repair loops, structured LLM outputs validated with Pydantic, and deterministic fallbacks so the system still behaves when the model doesn't.
